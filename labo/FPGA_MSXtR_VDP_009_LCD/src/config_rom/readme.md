# 概要

config_rom は、ip_spi_rom を使用して、FPGA の Configration ROM を読み書きするためのモジュールである。
config_rom階層には、内部バス I/F と ip_spi_rom の接続を行うラッピング処理回路のみが含まれる。

# I/O ポート一覧

MSX の拡張I/Oポートを利用してアクセスする仕組みを提供する。

参考
- https://ngs.no.coocan.jp/doc/wiki.cgi/datapack?page=Appendix+A%2E5+%B3%C8%C4%A5I%2FO%A5%DD%A1%BC%A5%C8

使用するメーカーID は 64 (40h)。MSXtR および MSX2++ では、この番号をシステム用ID と定義する。

| ポート名 | 説明 |
|--|--|
|40h|メーカーID の読み書き。読むと反転が返る。|
|41h|デバイスの選択。読むと反転が返る。|
|42h|コマンドポート|
|43h|データポート|
|44h-4Fh|予約|

メーカーID に 64 を書き込むと 41h のポートが有効になる。
41h にデバイス番号 1 を書き込むと、42h および 43h のポートが有効になる。

デバイス番号は 0, 2～255 は、別のデバイスにつながり、42h～4Fh の意味が切り替わる。したがって、デバイス番号が異なる場合にはこのコントローラーは反応しない。

## 存在の確認

- 40h に 40h を書き込む
- 40h を読み出し、反転した BFh が返ってくることを確認する
- 41h に 1 を書き込む
- 41h を読み出し、反転した FEh が返ってくることを確認する

## FlashROM の選択

ConfigROM の CS は、srom1_cs_n を使用する。
